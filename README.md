# ScoutFrame — Download

**ScoutFrame** é um editor tático de vídeo de futebol para Windows: importe seu vídeo, anote com setas, círculos, spotlight, linhas táticas e texto, controle cortes, velocidade e congelamentos, e exporte o MP4 final pronto para apresentação.

## ⬇️ Download

**[Baixar a versão mais recente (Windows)](https://github.com/leorfoletto/scoutframe-releases/releases/latest/download/ScoutFrame-setup.exe)**

Ou veja todas as versões na [página de releases](https://github.com/leorfoletto/scoutframe-releases/releases).

## Requisitos

- Windows 10 ou 11, 64 bits
- ~500 MB de espaço livre
- A instalação é por usuário e **não pede permissão de administrador**

## Aviso do Windows SmartScreen

Ao executar o instalador, o Windows pode mostrar *"O Windows protegeu o computador"* — isso acontece porque o instalador ainda não tem assinatura de código comercial, não por qualquer problema no arquivo. Para prosseguir:

1. Clique em **Mais informações**
2. Clique em **Executar assim mesmo**
